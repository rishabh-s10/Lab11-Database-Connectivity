LAB 11 – DATABASE CONNECTIVITY

Project: Film/Theatre Production Management Database
Main Table: PERSON

Files:
1. app.py – Tkinter frontend application.
2. db.py – Database connection and CRUD operations.
3. db_config.py – Database configuration.
4. test_crud.py – CRUD testing script.
5. requirements.txt – Required Python package.

Requirements:
- Python
- PostgreSQL
- psycopg2-binary

Instructions to run:

1. Install dependencies:
   pip install -r requirements.txt

2. Update the PostgreSQL password in db_config.py.

3. Run the application:
   python app.py
